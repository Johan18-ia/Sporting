====================================================
        MANUAL DE INSTALACIÓN Y EJECUCIÓN
====================================================

====================================================
1. INGRESAR A LA CARPETA DEL PROYECTO
====================================================

Paso 1:
cd .\frontend_web\backend\

Alternativo:
Abrir directamente la carpeta backend desde la terminal.

====================================================
2. CONFIGURAR O VERIFICAR IP
====================================================

Ejecutar en la terminal:

ipconfig

====================================================
3. INSTALAR DEPENDENCIAS
====================================================

Paso 1:
npm i

====================================================
4. INICIAR SERVIDOR
====================================================

Paso 1:
Iniciar XAMPP y activar:
- Apache
- MySQL

Paso 2:
Ejecutar el servidor:

node index.js

====================================================
5. DETENER EL SERVIDOR
====================================================

Presionar:

Ctrl + C

====================================================
6. SOPORTE
====================================================

En caso de errores o problemas:
Consultar con Jhon.

====================================================
7. REINSTALAR DEPENDENCIAS MANUALMENTE
====================================================

Si se pierden las dependencias del proyecto:

backend> npm i bcryptjs@3.0.2
backend> npm i cors@2.8.5
backend> npm i dotenv
backend> npm i express@4.21.2
backend> npm i http@0.0.1-security
backend> npm i jsonwebtoken@9.0.2
backend> npm i morgan@1.10.0
backend> npm i mysql@2.18.1
backend> npm i passport@0.4.1
backend> npm i passport-jwt@4.0.1
backend> npm i swagger-jsdoc
backend> npm i swagger-ui-express
backend> npm i -D nodemon

====================================================
8. REPARAR VULNERABILIDADES
====================================================

Ejecutar:

backend> npm audit fix

Si persisten errores:

backend> npm audit fix --force

====================================================
                MANUAL BÁSICO DE GIT
====================================================

====================================================
1. CONFIGURAR GIT
====================================================

Configurar nombre:
git config --global user.name "Tu Nombre"

Configurar correo:
git config --global user.email "correo@gmail.com"

Ver configuración actual:
git config --list

====================================================
2. INICIALIZAR GIT EN UN PROYECTO
====================================================

git init

====================================================
3. CLONAR UN REPOSITORIO
====================================================

git clone URL

Ejemplo:
git clone https://github.com/usuario/proyecto.git

====================================================
4. CONECTAR REPOSITORIO REMOTO
====================================================

git remote add origin URL_DEL_REPOSITORIO

Ejemplo:
git remote add origin https://github.com/usuario/proyecto.git

====================================================
5. VERIFICAR ESTADO DEL PROYECTO
====================================================

git status

Muestra:
- Archivos modificados
- Archivos nuevos
- Archivos listos para commit

====================================================
6. AGREGAR ARCHIVOS
====================================================

Agregar un archivo:
git add archivo.js

Agregar todos:
git add .

====================================================
7. GUARDAR CAMBIOS (COMMIT)
====================================================

git commit -m "Mensaje del commit"

Ejemplo:
git commit -m "Se agrega login con JWT"

====================================================
8. VER HISTORIAL DE COMMITS
====================================================

Historial completo:
git log

Versión corta:
git log --oneline

====================================================
9. SUBIR CAMBIOS A GITHUB
====================================================

Primera vez:
git push -u origin main

Después:
git push

====================================================
10. DESCARGAR CAMBIOS
====================================================

git pull

====================================================
11. MANEJO DE RAMAS
====================================================

Ver ramas:
git branch

Crear nueva rama:
git checkout -b nombre-rama

Cambiar de rama:
git checkout main

====================================================
12. TRAER CAMBIOS SIN MEZCLAR
====================================================

git fetch

====================================================
13. FLUJO DE TRABAJO MÁS USADO
====================================================

git status

git add .

git commit -m "Cambios realizados"

git push
