ARCHIVO: backend/config/swagger.js
---------------------------------------------------------------------------

                                    ↑
                               IP POR DEFECTO

 EJEMPLO:

-----------------------------------------------------------

ARCHIVO: backend/index.js
---------------------------------------------------------------------------

                             ↑
                    ESTA IP ESTÁ BIEN (0.0.0.0 significa "todas las interfaces")
                    NO LA CAMBIES A MENOS QUE SEA NECESARIO

 EXPLICACIÓN:
0.0.0.0 permite que el servidor escuche en todas las interfaces de red
de tu computadora. Es correcto mantenerlo así.

---------------------------------------------------------------------------

 10. PROBLEMAS COMUNES Y SOLUCIONES
================================================================================

PROBLEMA: "ERR_CONNECTION_REFUSED"
---------------------------------------------------------------------------
SOLUCIÓN: 
1. Verificar que el servidor backend esté corriendo
2. Verificar firewall (permitir puerto 3000 y 5173)
3. Verificar que la IP sea correcta

PROBLEMA: "CORS error"
---------------------------------------------------------------------------
SOLUCIÓN:
1. Verificar que la IP esté en la lista de CORS en server.js
2. Agregar la IP manualmente si es necesario

PROBLEMA: "No se puede conectar a la base de datos"
---------------------------------------------------------------------------
SOLUCIÓN:
1. Verificar que MySQL esté corriendo
2. Verificar DB_HOST en .env
3. Verificar credenciales de MySQL

PROBLEMA: "Token inválido o expirado"
---------------------------------------------------------------------------
SOLUCIÓN:
1. Verificar JWT_SECRET en .env
2. Limpiar localStorage del navegador
3. Volver a iniciar sesión

 11. CONFIGURACIÓN PARA MÚLTIPLES DISPOSITIVOS EN LA MISMA RED
================================================================================

Si quieres que otros dispositivos accedan a la aplicación:

1. Asegurar que todos estén en la misma red (WiFi/LAN)
2. Usar la IP local del servidor (ej: 192.168.1.100)
3. Desde otro dispositivo abrir: http://192.168.1.100:5173
4. Los firewalls deben permitir la conexión

 18. PARA PRODUCCIÓN
================================================================================

Para desplegar en producción (servidor en internet):

1. Usar un dominio en lugar de IP:
   VITE_API_URL=https://midominio.com/api

2. Configurar SSL/HTTPS:
   Usar certificados SSL para conexiones seguras

3. Usar variables de entorno en el servidor de producción:
   Configurar las variables de entorno directamente en el hosting

4. Configurar el firewall para permitir solo los puertos necesarios

5. Usar PM2 o similar para mantener el servidor corriendo:
   npm install -g pm2
   pm2 start index.js --name sporting-backend
   pm2 save
   pm2 startup
