========
3. Configura tu red para conexión móvil (IMPORTANTE)
Para que el QR funcione correctamente:

Opción A: Misma red WiFi

Asegúrate que tu computadora y celular estén en la misma red WiFi

Desactiva cualquier VPN o firewall que pueda bloquear la conexión

Opción B: Usar túnel ngrok (recomendado si tienes problemas)

bash
npm install -g ngrok
# Luego, en una terminal separada
ngrok http 8081
Opción C: Usar la IP local de tu computadora (fallback)

bash
# En Windows (CMD)
ipconfig
# En Mac/Linux
ifconfig
# Busca tu IP local (ej: 192.168.x.x)
