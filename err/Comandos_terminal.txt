====================================================
                MANUAL BÁSICO DE GIT
====================================================

====================================================
1. CONFIGURAR GIT
====================================================

Configurar nombre:
git config --global user.name "Tu Nombre"

Configurar correo:
git config --global user.email "correo@gmail.com"

Ver configuración actual:
git config --list

====================================================
2. INICIALIZAR GIT EN UN PROYECTO
====================================================

git init

====================================================
3. CLONAR UN REPOSITORIO
====================================================

git clone URL

Ejemplo:
git clone https://github.com/usuario/proyecto.git

====================================================
4. CONECTAR REPOSITORIO REMOTO
====================================================

git remote add origin URL_DEL_REPOSITORIO

Ejemplo:
git remote add origin https://github.com/usuario/proyecto.git

====================================================
5. VERIFICAR ESTADO DEL PROYECTO
====================================================

git status

Muestra:
- Archivos modificados
- Archivos nuevos
- Archivos listos para commit

====================================================
6. AGREGAR ARCHIVOS
====================================================

Agregar un archivo:
git add archivo.js

Agregar todos:
git add .

====================================================
7. GUARDAR CAMBIOS (COMMIT)
====================================================

git commit -m "Mensaje del commit"

Ejemplo:
git commit -m "Se agrega login con JWT"

====================================================
8. VER HISTORIAL DE COMMITS
====================================================

Historial completo:
git log

Versión corta:
git log --oneline

====================================================
9. SUBIR CAMBIOS A GITHUB
====================================================

Primera vez:
git push -u origin main

Después:
git push

====================================================
10. DESCARGAR CAMBIOS
====================================================

git pull

====================================================
11. MANEJO DE RAMAS
====================================================

Ver ramas:
git branch

Crear nueva rama:
git checkout -b nombre-rama

Cambiar de rama:
git checkout main

====================================================
12. TRAER CAMBIOS SIN MEZCLAR
====================================================

git fetch

====================================================
13. FLUJO DE TRABAJO MÁS USADO
====================================================

git status

git add .

git commit -m "Cambios realizados"

git push

====================================================
            14. MANEJO DE RAMAS EN GIT
====================================================

Las ramas permiten trabajar en nuevas funciones o cambios
sin afectar directamente la rama principal del proyecto.

====================================================
15. VER LAS RAMAS EXISTENTES
====================================================

Ver ramas locales:
git branch

Ver ramas remotas:
git branch -r

Ver todas las ramas:
git branch -a

La rama actual aparecerá con un *

Ejemplo:
* main
  desarrollo-login

====================================================
16. CREAR UNA NUEVA RAMA
====================================================

Crear y cambiar automáticamente a una nueva rama:

git checkout -b nombre-rama

Ejemplo:
git checkout -b desarrollo-login

====================================================
17. CAMBIAR ENTRE RAMAS
====================================================

Cambiar a la rama principal:
git checkout main

Cambiar a otra rama:
git checkout nombre-rama

Ejemplo:
git checkout desarrollo-login

====================================================
18. GUARDAR CAMBIOS EN UNA RAMA
====================================================

Paso 1:
Verificar cambios

git status

Paso 2:
Agregar archivos

git add .

Paso 3:
Guardar commit

git commit -m "Descripción de cambios"

Ejemplo:
git commit -m "Se agrega autenticación JWT"

====================================================
19. SUBIR UNA RAMA A GITHUB
====================================================

Primera vez:

git push -u origin nombre-rama

Ejemplo:
git push -u origin desarrollo-login

Después de la primera vez:

git push

====================================================
20. ACTUALIZAR MAIN
====================================================

Cambiar a la rama principal:

git checkout main

Actualizar cambios desde GitHub:

git pull origin main

====================================================
21. ACTUALIZAR UNA RAMA CON CAMBIOS DE MAIN
====================================================

Paso 1:
Ir a main

git checkout main

Paso 2:
Actualizar main

git pull origin main

Paso 3:
Volver a tu rama

git checkout nombre-rama

Paso 4:
Traer cambios de main

git merge main

====================================================
22. UNIR UNA RAMA A MAIN
====================================================

Paso 1:
Cambiar a main

git checkout main

Paso 2:
Actualizar main

git pull origin main

Paso 3:
Unir la rama

git merge nombre-rama

Ejemplo:
git merge desarrollo-login

Paso 4:
Subir cambios actualizados

git push origin main

====================================================
23. ELIMINAR UNA RAMA
====================================================

Eliminar rama local:

git branch -d nombre-rama

Ejemplo:
git branch -d desarrollo-login

Eliminar rama remota:

git push origin --delete nombre-rama

====================================================
24. TRAER CAMBIOS SIN MEZCLAR
====================================================

git fetch

====================================================
25. FLUJO DE TRABAJO RECOMENDADO
====================================================

1. Actualizar main

git checkout main
git pull origin main

2. Crear nueva rama

git checkout -b nueva-funcionalidad

3. Realizar cambios

git add .
git commit -m "Nueva funcionalidad"

4. Subir rama

git push -u origin nueva-funcionalidad

5. Unir cambios a main

git checkout main
git pull origin main
git merge Jhon --en caso de la rama jhon
git push origin main

====================================================
26. CONSEJOS IMPORTANTES
====================================================

- No trabajar directamente sobre main
- Crear una rama por funcionalidad
- Hacer commits claros y organizados
- Actualizar main constantemente
- Revisar git status antes de hacer commit
- Hacer pull antes de merge
- Resolver conflictos antes de subir cambios
